# Портфолио учебных работ

Минималистичный одностраничный сайт на чистом HTML и CSS, созданный для хранения и просмотра работ для учебы - отчетов по учебной практике, практическим и лабораторным работам в формате PDF.

**Посмотреть сайт:** [Открыть на GitHub Pages](https://victoriausolceva.github.io/optimizacia/)

Страница выполнена в строгом черно-белом стиле, адаптирована под мобильные устройства и включает фиксированный фоновый блок с градиентом в нижней части экрана.
